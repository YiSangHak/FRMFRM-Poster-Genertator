# FRMFRM Modular Poster Editor

React + TypeScript + Vite로 만든 로컬 포스터 에디터입니다. 별도 백엔드는 없습니다.

## 실행

Node.js 20.19+ 또는 22.12+를 설치한 환경에서 프로젝트 폴더를 열고 실행합니다.

```sh
npm install
npm run dev
```

안내된 로컬 주소(기본 http://127.0.0.1:5173)를 브라우저에서 엽니다. `pnpm install` / `pnpm dev`도 사용할 수 있습니다.

```sh
npm run build
npm test
```

## 편집

- R: 사각형 도구. 셀에서 드래그하면 하나의 사각형을 만듭니다.
- V: 선택 도구. 드래그 이동, 사각형 오른쪽 아래 핸들로 크기 변경.
- T: 텍스트 도구. 셀을 클릭하면 FRAME 텍스트가 추가됩니다.
- 프리셋 클릭 또는 캔버스로 드래그: 텍스트 추가.
- 로고 버튼: 실제 OTF 글리프 패스로 구성된 6칸 로고 추가.
- Cmd/Ctrl+D: 복제. Alt/Option+드래그: 복제 이동.
- 방향키: 1칸, Shift+방향키: 2칸 이동.
- Delete/Backspace: 삭제. Cmd/Ctrl+Z: 취소, Cmd/Ctrl+Shift+Z: 다시 실행.
- 입력창 작성 중에는 편집 단축키가 작동하지 않습니다.
- 반복 개수는 원본을 포함합니다. 간격은 점유 영역 끝과 다음 요소 사이의 빈 셀 수입니다. 그리드를 벗어나는 반복은 실행하지 않습니다.
- 모든 열/행 입력은 1부터 표시하며 내부 좌표는 0부터 저장합니다.
- 색상을 개별 지정하면 배경 전환에도 유지됩니다. `자동`을 누르면 배경 대비 색상을 따릅니다.
- 요소와 시안 삭제는 실행 취소로 복구할 수 있습니다. 실행 취소 기록은 메모리에 최대 100개 저장됩니다.

## 정확한 규격

아트보드 330×450mm, 여백 15mm, 10×14 그리드, 셀 30mm. 사각형은 `x=16.5+30×col`, `y=16.5+30×row`, `width=30×w−3`, `height=30×h−3`입니다. 셀별 조각 없이 하나의 rect로 그립니다.

십자 마커는 165개이며 3mm 길이, 0.75pt 선입니다. 배경 → 마커 → 사용자 레이어 순서로 렌더링하므로 큰 사각형이 내부 마커를 가리고 외곽 마커는 유지합니다. 편집용 가이드는 SVG에서 제외됩니다.

## 서체와 SVG

- `public/assets/fonts/FRMFRM-Regular.woff2`: 영문 Geist Sans / 한글 Pretendard 합성글꼴. 정보 텍스트 기본값, 12pt, 자간 −0.03em.
- `public/assets/fonts/Geist-Regular.woff2`: 영문 기본 서체.
- `public/assets/fonts/FRMFRMMONO-Regular.otf`: 로고. 실제 바운딩 박스를 기준으로 글자마다 높이 27mm, 모듈 중앙 배치.
- 기존 `assets/` 원본도 유지했습니다. 웹에서 사용되는 파일을 교체하려면 `public/assets/fonts/`를 수정합니다.

SVG는 330mm×450mm, `viewBox="0 0 330 450"`입니다. 사각형은 rect, 정보 텍스트는 text, 로고는 원본 OTF의 path로 출력합니다. 요소별 g 그룹이 유지됩니다. 브라우저용 합성 WOFF2를 SVG에 포함하지만 Illustrator가 이를 해석한다고 보장하지 않으므로 편집할 컴퓨터에 같은 합성글꼴을 설치하세요.

**Outlined SVG 전체 출력은 미지원으로 비활성화되어 있습니다.** 합성 WOFF2 정보 텍스트의 외곽선 변환은 구현하지 않았습니다. 로고만 실제 글리프 패스로 출력합니다. Illustrator에서 직접 열어 보는 검증은 수행하지 않았습니다.

## 저장

Local Storage에 자동 저장되며 같은 브라우저와 주소에서 복원됩니다. 포트/브라우저를 변경하면 별도 저장소가 됩니다. 장기 보관은 JSON 프로젝트 저장을 사용하세요. 불러오기는 모든 시안과 배경, 요소, 좌표, 색상, 레이어를 복원합니다. 실행 취소 이력과 편집 화면 확대율은 저장하지 않습니다.

## 파일 구조

```text
src/main.tsx          편집 UI, 상태, 조작, 저장과 SVG 출력
src/geometry.mjs      사각형 규격과 165개 마커 좌표
src/style.css         UI와 서체
public/assets/fonts/  웹에서 불러오는 서체
assets/               제공된 원본 서체
tests/                규격 및 실제 OTF 검증
```

브라우저에서 사각형 생성·규격·스냅 이동, 한영 텍스트, 반복, 로고, 시안 복제 및 흑백 비교, 실제 SVG 다운로드를 확인했습니다. SVG 파일의 실제 mm 크기, 마커 수, rect 크기, text와 로고 path도 검사했습니다.
